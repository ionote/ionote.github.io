# ioNote

Quick notes, ready when you need them.

https://ionote.github.io

## Get started

Open ioNote and tap **+**. Notes save as you type. Press and hold a note (or right-click) to pin or delete it; deleted notes can be restored for a few seconds.

Install it from your browser if you want it to open like an app:
- Android, Chrome: **Install and create shortcut**.
- iPhone or iPad, Safari: **Share → Add to Home Screen**.
- Computer, Chrome or Edge: use the install icon in the address bar.

Computer shortcuts: **N** new note, **/** search, **Esc** back.

## Backups

Notes stay in this browser on this device. Clearing browser data deletes them. In **Settings**, choose **Save backup**. **Restore backup** adds notes without deleting existing ones.

## Privacy and encryption

ioNote has no account, server, or analytics. Optional **Encryption** is available in **Settings**. Use a passphrase of at least 12 characters and save a backup first; a forgotten passphrase cannot be recovered.
